# ReAct Planning Agent

A ReAct (Reason + Act) planning agent that observes, thinks, acts and reflects —
with hard iteration limits, loop detection, self-critique and graceful degradation,
so it never loops forever.

Development is spec-driven with [OpenSpec](https://github.com/Fission-AI/OpenSpec):
see `openspec/` for specs and change proposals.
